# UI 操作速查 · 目录与配置

更新：2026-11-15。对应当前卡片式工具 / 项目 / 插件设置 UI。
完整安装、配置、MCP、备份和排障步骤见 **[使用指南手册](usage.md)**。

## 1. 页面入口

在 magpie 侧边栏打开 **团队目录**。浏览器备用入口默认是
`http://127.0.0.1:3969/`，实际以插件 servicePort 为准。

| 页面区域 | 用途 |
| --- | --- |
| 顶部统计 | CLI 工具、项目 / 工作区、本机已发现、需关注 |
| 工具 | 搜索 / 筛选工具、注册 CLI、扫描 npm、编辑个人条目或覆盖本机路径 |
| 项目 | 搜索 / 筛选项目、按 Client 分组、发现 Git / P4、注册与绑定本机目录 |
| 插件设置 | 团队 registry、个人文件、周期 / 超时 / 并发及高级分发配置 |
| 刷新视图 | 重新读取目录与已有状态，不等于执行新一轮检查 |
| 立即重跑探测 | 触发后台检查已注册工具与本机项目，不查询 P4 服务器 |

顶部已发现数量不证明登录或权限；项目卡片的 Git 分支不证明工作树干净。

## 2. 常用操作速查

| 想做什么 | 操作路径 |
| --- | --- |
| 添加已安装的内部 CLI | 工具 → 新增个人 CLI → 填常用字段 → 保存并探测 |
| 从 npm 全局命令选工具 | 工具 → 扫描 npm CLI → 筛选候选 → 选择注册 → 补维护说明 → 保存并探测 |
| 更新个人工具说明 | 工具卡片 → 编辑注册 → 保存并探测 |
| 移除个人工具 | 工具卡片 → 移除注册 → 确认移除；不卸载 CLI |
| 设置真实启动路径 | 卡片 → 本机覆盖 → 启动路径覆盖 → 应用到待保存修改 → 保存本机覆盖 |
| 临时禁用工具 | 卡片 → 本机覆盖 → 启用改为禁用 → 应用到待保存修改 → 保存本机覆盖 |
| 恢复自动探测 | 本机覆盖 → 恢复自动 → 应用到待保存修改 → 保存本机覆盖 |
| 新增本机 Git/P4 项目 | 项目 → 新增本机项目 → 保存项目 |
| 发现本地 Git 仓库 | 项目 → 发现 Git 目录 → 根目录 / 最大深度 → 开始发现 → 选择注册 |
| 只读查已有 P4 Client | 项目 → 发现 P4 工作区 → 服务器只读查询 → 填连接 / 勾选授权 → 开始发现 |
| 离线读 P4CONFIG | 项目 → 发现 P4 工作区 → 离线 P4CONFIG 文件 → 填路径 → 开始发现 |
| 绑定团队项目 | 团队项目卡片 → 绑定本机目录 → 保存项目 |
| 解除绑定 | 同一绑定弹窗 → 解除绑定 → 确认；不删目录或团队项目 |
| 移除本机项目 | 个人项目卡片 → 移除项目 → 确认；不删除目录或 P4 Client |
| 改检查周期 | 插件设置 → 检查周期（秒） → 保存插件设置 |
| 关闭个人注册层 | 插件设置 → 个人注册层关闭 → 保存；个人文件保留 |

## 3. 搜索与分组

- 工具支持名称、包名、路径、用法搜索；项目支持名称、目录、Client 与 Depot 搜索。
- 多个关键词都需要命中该条目，可配合来源、类型和状态筛选。
- 项目按 Git / 普通目录以及 P4 server + Client 分组，标题显示组内数量。
- P4 工作区下拉筛选 Client；组标题可折叠，长说明、View 和地址收在详情中。
- 切换页签会重置搜索 / 筛选，不会移除条目；同一页面中组折叠状态保留。
- 页面整体重新加载后，筛选 / 折叠内存状态可能重置，不使用 localStorage。
- 当前目录索引位于插件设置底部；默认仅展示，不注入 system prompt。

## 4. 编辑表单

### CLI

常用字段：ID、名称、安装渠道、包名、命令名 / 绝对路径、安装 / 更新说明、用法摘要。
高级字段：版本参数、超时、最低版本、Skill ID、相对文档路径与详细文档。

- ID 使用小写字母、数字与连字符，最长 48 字符，工具 / 项目之间也不能重复。
- 安装说明必填但不执行；安装渠道为本机二进制时无需包名。
- 版本参数是固定 JSON 字符串数组，常用 `["--version"]`，P4 用 `["-V"]`。
- 没有版本命令可用 `[]`；npm 版本从清单读取，二进制可能没有版本显示。
- 不把构建、登录或验证用例填为周期探测命令。

### 项目与 P4

- 本机根目录必须绝对路径；只有 P4 类型显示 P4 连接字段。
- **从已注册工作区填充**仅预填 port / user / client，不联网，不替你确认 Depot 范围。
- P4 发现中的 **已有 P4 连接**预填后会清除授权勾选，查询前需重新确认。
- 团队绑定表单的 ID / 名称 / 地址只读，修改的仅是本机路径与 P4 上下文。
- 具体 UE 文件、EngineAssociation 可记在项目说明；没有通用一键批量扫描 / 导入按钮。

## 5. 草稿与保存

**本机覆盖要保存两次？** 不是：第一步“应用到待保存修改”只暂存，第二步
“保存本机覆盖”才写盘。可先调整多个工具，再统一保存。

| 当前修改 | 持久化动作 | 保存后 |
| --- | --- | --- |
| CLI / 项目注册表单 | 保存并探测 / 保存项目 | 写个人目录，触发后台检查 |
| 本机覆盖弹窗 | 应用到待保存修改 | 只暂存；还需保存条写盘 |
| 待保存覆盖 | 保存本机覆盖 | 写插件 options，宿主重载 |
| 设置表单 | 保存插件设置 | 写白名单字段，宿主重载 |

后台刷新不覆盖编辑弹窗、待保存覆盖和设置草稿。取消 / Escape 关闭未保存编辑
会显示 DOM 确认框；取消确认可继续编辑，确认放弃才丢弃当前输入。

## 6. 设置与安全确认

- 检查周期 60–86400 秒，命令超时 100–60000 毫秒，并发 1–32。
- 个人文件留空用默认目录，关闭层保留文件；文件不能放插件目录内。
- Skill 导出需 skillsRepo，提示词注入与 Skill 导出默认关闭。
- 普通表单只写白名单，保留发布 index、未知用户键和未提供的高级路径配置。
- 配置使用 revision 并发校验；旧窗口保存被拒绝，输入保留，不覆盖新配置。
- 设置保存前应先处理本机覆盖草稿；切换页签放弃设置需确认。
- 编辑保存期间冻结字段，操作按钮防重复点击；失败显示错误，不清空输入。
- 页面会话失效时空闲页自动恢复；有草稿保留并提示重载，不自动重放写操作。
- 所有确认都在页面内完成，不依赖沙箱禁止的原生 window.confirm。

## 7. 验收与限制

已验证搜索 / 分组、覆盖保存、草稿刷新、设置冲突、取消放弃、CLI / 项目删除确认和候选提示；
小窗口无横向溢出。新页面脚本内联，兼容 magpie opaque-origin iframe。

UI 不自动安装、卸载、Git 拉取或 P4 同步 / 提交；服务器查询需要单独授权。
首次加载已保留的旧版 GUI 文档可能需重新打开页面。注册数据与页面状态分离，
重新加载会丢未保存输入，但不会删除已保存个人目录。
