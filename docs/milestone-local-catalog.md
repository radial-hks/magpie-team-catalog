# 阶段交付：本机核心目录基础

日期：2026-11-15。阶段目标：团队声明与个人注册合并后，能在本机安全探测、
通过 GUI 管理、通过 MCP 查询；安装维护仍交给原有包管理器/团队流程。

## 已交付

- Windows 原生程序与 `.cmd/.bat` 执行兼容；按当前 PATH/PATHEXT 查找启动器，
  不误选 npm 的 POSIX shim；同步 spawn 异常 fail-open。
- 显式 magpieBin 路径失效不回退到其它本机安装；测试注入发布通道，避免触碰真实配置。
- 团队 registry + 插件目录外的个人注册文件 + 本机覆盖三层配置。
- 个人 CLI GUI 增删改：安装渠道、package、bin、固定版本参数、用法、文档。
- npm 全局 CLI 候选扫描：只读包清单/bin 元数据，由用户确认后注册；不执行候选。
- 显式 package 匹配，支持包名与命令不同；清单命中仍输出真实可执行路径。
- 冲突检查、revision CAS、保存锁与原子替换；坏目录不覆盖原文件、不清理 Skill。
- GUI 编辑器/会话脚本内联提供；会话校验、公开实例 ID 检查与过期恢复。
  空闲页重载，有未保存修改则保留输入并提示，不自动重放 POST。
- P4 Rev 版本解析优先于 OpenSSL 依赖版本；默认目录移除 sentinel-maa 项目条目。

## 验收

- 本机 Bun 1.3.9、原宿主 Bun 1.4.2 与当前宿主 Bun 1.4.4：`bun test`，107 项测试通过。
- 真实浏览器：npm 候选选择、创建/编辑/删除个人 CLI，无脚本错误；
  opaque-origin iframe 可用；含令牌主文档不能由其它网站跨域读取。
- 原生 magpie GUI：工具表与新增/扫描按钮可见，新增注册弹窗可打开。
- 页面过期恢复：浏览器模拟 403 和实例轮换验证通过，未保存表单保留、不重放写操作。
  已加载的旧版 GUI 页面不具备恢复逻辑，首次升级需重新打开页面。
- 本机后台 worker 更新、MCP 查询与个人文件一致；定时刷新实测后恢复 900 秒周期。
- 本机注册实例：ueb（npm 同名命令）、p4（binary）、wdp-verify（npm 包名
  wdp-api-verify 与命令名不同）。这些实例仅保存于用户配置目录，不提交入默认 registry。
- wdp-api-verify 从本机源码构建 tgz 全局安装：41 项自身单测通过，隔离 mock
  验证变量保存/插值与报告生成；未修改该项目源码，未连接真实编辑器。

## 本阶段边界 / 后续

- 不自动安装、升级 CLI；不自动运行候选、真实 API 用例、P4 登录或提交。
- Skill 导出与提示词注入默认关闭；个人 CLI 沿用现有技能源/托管同步机制，
  不自动导入 npm 包内 Skill。magpie library hand-over/sync 的工作机验收仍待完成。
- 团队 npm 发布、共享 registry/Skill 仓库治理、双机同步验证仍属于后续工作。
- Windows 已双运行时验证；Linux/macOS 没有本阶段实机验证，跨平台夹具需继续 CI 覆盖。
- 本地服务只监听 loopback；页面令牌不是针对同权限恶意本机进程的安全沙箱。
- 文件写锁进程异常退出后可能残留，确认无保存进程后需手动清理；外部文件编辑
  不应与页面并发保存。页面轮询/宿主退役窗口的进一步优化留到后续。

本阶段提交只包含源码、测试、文档与明确的默认目录变更；不包含本机状态、个人注册、
安装 tgz/mock 报告、登录票据或凭据。不发布 npm，不推送远端。
